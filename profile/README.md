# HeadDeck

### Open-source Headscale management, made simpler.

Welcome to **HeadDeck**, a community-driven project building a modern web interface for [Headscale](https://github.com/juanfont/headscale).

Our goal is to make Headscale network administration more accessible through an intuitive dashboard, while preserving the flexibility and control of self-hosted infrastructure.

## What is HeadDeck?

HeadDeck is a web-based management interface for Headscale, the open-source, self-hosted Tailscale control server.

It is designed to provide a centralized interface for managing your Headscale network without requiring a separate application database.

### What we're building

- **Network Overview** — Monitor nodes, users, routes, and connectivity.
- **Node Management** — Inspect and manage registered devices.
- **User Management** — Organize users and their associated nodes.
- **Pre-authentication Keys** — Manage device registration credentials.
- **Access Policies** — Edit and validate network access policies.
- **API Key Management** — Manage Headscale API credentials.
- **Secure Authentication** — API-key-based authentication and protected sessions.
- **Modern Interface** — Responsive design with light and dark themes.

## Project Status

**HeadDeck is currently under active development.**

The initial user interface has been completed. Headscale API integration, authentication, and functional testing are the next development milestones.

The project is not yet ready for production deployments.

Follow development through the [main repository](https://github.com/headdeck/headdeck).

## Technology

HeadDeck is built using Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, Auth.js, and Zod.

It is designed around a lightweight architecture, with Headscale remaining the source of truth.
